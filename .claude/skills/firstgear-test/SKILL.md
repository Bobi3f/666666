# Тесты FIRST GEAR

Godot 4.5.1 ставит хук начала сессии (`.claude/hooks/session-start.sh`) в
`~/.local/bin/godot` и пишет путь в `$GODOT`. Если его нет — запусти хук:
`CLAUDE_CODE_REMOTE=true .claude/hooks/session-start.sh`.

## Запуск

```bash
tests/run_all.sh                      # всё: ~10 минут
tests/run_all.sh check_scripts        # только компиляция всех скриптов (10 с)
tests/run_all.sh test_gai test_view   # выбранные наборы
```

Каждый набор печатает `ИТОГО: всё работает` или список `FAIL`. Полные журналы —
в `/tmp/firstgear-tests/<набор>.log`. Код выхода 1, если что-то упало.

Порядок работы после правки:
1. `tests/run_all.sh check_scripts` — компилируется ли всё.
2. Наборы, которые касаются правки (таблица ниже).
3. Перед коммитом — `tests/run_all.sh` целиком.

| Набор | Что проверяет |
|---|---|
| check_scripts | все `scripts/**/*.gd` компилируются вместе с автозагрузками |
| test_vehicles, test_driving | физика машин, мотоцикл, автомат/механика, заезды |
| test_salon | автосалон, Нива/Волга/ГАЗ-53, разгон |
| test_life, test_mvp, test_round3 | жители, задания, такси, коровы, экономика |
| test_village | распорядок жителей, поручения, ярмарка, своё дело, сберкасса, радио |
| test_seasons | сезоны, небо, трактор, огород, приборы |
| test_polish, test_gai | вода, птицы, гроза, достижения, ГАИ, грибы, животные |
| test_roads_town | дороги, светофор, плавная камера |
| test_tutorial_save | обучение, сохранение/загрузка |
| test_soak | 30 игровых дней подряд: утечки узлов, деньги, покупки |
| test_touch, test_view, test_options, test_menu_pad | телефон (руль, джойстик, вид со спины), настройки, меню с геймпада — под xvfb |

## Как устроен тест

Скрипт `extends SceneTree`: грузит `res://scenes/World.tscn`, в `_run()`
закрывает меню (`pause_menu.gd` → `_close()`), обучение (`tutorial.gd` →
`_finish()`), при необходимости убирает трафик, затем проверяет через
`ok(условие, "что проверили")` и в конце печатает строку `ИТОГО`. Шаблон —
любой из `tests/test_*.gd`. Новый набор добавь в `HEADLESS` или `SCREEN` в
`tests/run_all.sh`.

## Ловушки

- Флаг `--no-menu` отключает автоснижение детализации (`SettingsManager._auto`).
- Наборы пишут общее сохранение `user://save.json` — запускай по одному
  (так делает run_all.sh), а тест, который сохраняет, должен убирать за собой.
- Проверки времени кадра (камера) чувствительны к нагрузке — не запускай
  параллельно тяжёлые процессы.
- Игрок остаётся в машине, если скорость > 2 м/с: `exit_car()` откажет.
  Обнули `speed` и `velocity` перед выходом.
- `SCRIPT ERROR: Identifier not found: GameManager` в начале журнала при
  разборе самого теста до загрузки автозагрузок — безвредно, если дальше
  `ИТОГО` без провалов.

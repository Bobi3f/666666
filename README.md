# FIRST GEAR — 3D, оптимизированная версия

Постсоветский life-sim от первого лица. Godot 4.3+, GDScript.

## Как запустить
Godot 4.3+ (Standard) → Import → выбрать `project.godot` → Import & Edit → F5.

## Почему эта версия не тормозит

Видеокарту грузит не количество треугольников, а количество **объектов** —
на каждый идёт отдельный вызов отрисовки. Прошлая версия создавала около
14 500 отдельных узлов: каждая доска забора, каждая черепица, каждая грядка.
Отсюда и были лаги.

Здесь вся неподвижная геометрия копится в общий буфер, а цвет пишется прямо
в вершины. На выходе — **один меш на весь мир**. Деревня, город, дороги, лес
и ЛЭП рисуются за один вызов.

| | Старая версия | Эта |
|---|---|---|
| Объектов в сцене | ~14 500 | 2-3 |
| Вызовов отрисовки | тысячи | ~8 |
| Треугольников | — | 42 тысячи (одним куском) |
| Режим отрисовки | Forward+ | Compatibility (OpenGL) |
| Сборка мира | создать и потом склеить | сразу одним мешем |

Коллизии стоят только там, где игрок реально может упереться: стены домов,
сараи, земля. Всё остальное — чистая геометрия без физики.

## Графика

Всё сделано так, чтобы не добавлять вызовов отрисовки — только геометрией
и цветом вершин:

- **Затенение у земли**: низ стен темнее верха, дом визуально стоит на земле,
  а не парит над ней. Стоит это ноль производительности — цвет и так лежит
  в вершинах.
- **Разброс цвета по граням**: большие плоскости перестали быть ровной заливкой.
- **Светящиеся окна**: часть окон горит изнутри, ночью деревня и город живые.
  Светящееся вынесено в отдельный меш — это +1 вызов отрисовки на весь мир.
- **Черепица рядами** по скатам крыш, печные трубы с колпаками.
- **Окна с наличниками**, переплётом крестом и подоконниками.
- **Заборы из штакетин** разной высоты, столбы с наклоном.
- **Деревья из повёрнутых кусков** кроны вместо коробки, с тенью на земле.
- **Земля пятнами** разного оттенка, грунтовые обочины, бордюры из отдельных
  камней с разнобоем, пешеходные переходы, отмостки вокруг домов.

Треугольников стало 66 тысяч вместо 42 — для видеокарты это по-прежнему
пустяк, потому что они идут одним куском.

## Что в игре
- Деревня из 8 дворов **трёх уровней достатка**:
  - **бедный** — бревенчатый дом с видными венцами под ржавым железом,
    покосившийся забор с выломанными штакетинами, уличный туалет,
    дрова навалом, две грядки;
  - **средний** — штукатуренный дом под шифером с верандой, ровный штакетник,
    колодец с воротом и навесом, бельевые верёвки, поленница штабелем;
  - **зажиточный** — кирпичный дом в два этажа с кладкой рядами, крыльцо
    с колоннами, спутниковая тарелка, пристроенный гараж с воротами,
    сплошной забор 1.9 м на кирпичных столбах, теплица, лавочка у ворот.
- Мир 400×400 м: город из 5 панельных домов с подъездами и балконами,
  магистраль
  с разметкой, тротуары, ЛЭП, лес, поля.
- Машина на механике: сцепление с точкой схватывания, проскальзывание дисков,
  заглохание, скрежет при переключении без сцепления. На первой можно
  тронуться без газа — машина ползёт на холостых.
- Мопед — без передач, проще.
- Время суток, погода, потребности, инвентарь, деньги, квесты, сохранения,
  синтезированный звук.

## Управление
F1 в игре — полный список. Коротко:

| Клавиша | Пешком | В машине |
|---|---|---|
| W A S D | идти | газ, тормоз, руль |
| Shift | бежать | **сцепление** |
| E | действие | выйти |
| R | — | зажигание |
| ] / [ | — | передача выше / ниже |
| Пробел | прыжок | ручник |
| F5 / F9 | сохранить / загрузить | |

### Как тронуться
1. Выжать сцепление (Shift), завести (R)
2. Не отпуская Shift, включить первую ( ] )
3. Отпустить Shift — машина тронется сама
4. Газ (W), переключаться: Shift + ]

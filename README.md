# FIRST GEAR — 3D

Постсоветский life-sim от первого лица. Godot 4.3+ (Compatibility), GDScript.

## Как запустить
Godot 4.3+ (Standard) → Import → выбрать `project.godot` → Import & Edit → F5.

Если F5 / F9 в игре не срабатывают, это редактор забирает F-клавиши себе.
Запустите игру в отдельном окне: Редактор → Настройки редактора → Run →
Window Placement → **Game Embed Mode = Disabled**. В собранной игре всё работает.

## Что в игре
- **Мир 400×400 м**: магистраль с разметкой и обочинами, ЛЭП, лес, поля,
  деревенская улица и съезд к трассе.
- **Деревня из 8 дворов трёх уровней достатка**, в каждый дом можно зайти:
  - **бедный** — сруб с пазами между брёвнами, ржавая крыша, синие наличники
    с кокошниками, покосившийся штакетник с выломанными досками, уличный туалет,
    дрова навалом, грядки;
  - **средний** — штукатурка, шифер, ровный штакетник, колодец с навесом,
    бельё на верёвке, поленница;
  - **зажиточный** — кирпичная кладка рядами, черепица, спутниковая тарелка,
    гараж, теплица, сплошной забор 1.9 м на кирпичных столбах, лавочка у ворот.
- **Интерьеры** (`scripts/world/house_interior.gd`): кухня и комната, окна со
  стеклом и занавесками, двери открываются сами, мебель и мелочи по достатку.
  Окна и двери фасада вырезаны ровно там же, где они внутри.
- **Город**: пять панельных пятиэтажек с подъездами и балконами, ночью горят окна,
  детская площадка, тротуар с бордюром.
- **Машина на механике**: сцепление с точкой схватывания и проскальзыванием дисков,
  заглохание, скрежет при переключении без сцепления. На первой можно тронуться
  без газа — машина ползёт на холостых.
- **Жизнь**: смена дня и ночи (сутки — 24 минуты), сытость и бодрость,
  деньги (старт — 10 000 грн).
  - **Ларёк** у перехода: батон и кефир за 45 грн, съесть — Q.
  - **Склад** в городе: смена грузчиком, 4 часа, +600 грн (с 6:00 до 20:00).
  - **Кровать** дома: сон до 7:00, бодрость до 100%.
- **Сохранение** F5 / **загрузка** F9: деньги, время, потребности, где игрок и машина.

## Почему не тормозит
Вся неподвижная геометрия копится в один меш с цветом в вершинах
(`scripts/core/mesh_builder.gd`): деревня, город, дороги, лес и ЛЭП рисуются
за один вызов отрисовки. Светящиеся окна — второй меш. Интерьер дома — один меш
на 6 поверхностей, издалека не рисуется.

## Управление
F1 в игре — полный список.

| Клавиша | Пешком | В машине |
|---|---|---|
| W A S D | идти | газ, тормоз, руль |
| Shift | бежать | **сцепление** |
| E | действие | выйти |
| Q | съесть еду из запаса | — |
| R | — | зажигание |
| ] / [ | — | передача выше / ниже |
| Пробел | прыжок | ручник |
| F5 / F9 | сохранить / загрузить | |

### Как тронуться
1. Выжать сцепление (держать Shift), завести (R)
2. Не отпуская Shift, включить первую ( ] )
3. Отпустить Shift — машина тронется сама
4. Газ (W), переключаться: Shift + ]

## Устройство кода
| Файл | Что делает |
|---|---|
| `scenes/World.tscn` | главная сцена, всё строится кодом |
| `scripts/world/world.gd` | мир: земля, дороги, деревня, город, ларёк, склад, лес |
| `scripts/world/house_interior.gd` | интерьер дома трёх уровней достатка |
| `scripts/core/mesh_builder.gd` | сборка геометрии в один меш |
| `scripts/player/player.gd` | персонаж от первого лица |
| `scripts/vehicles/car.gd` | машина с механической коробкой |
| `scripts/core/*_manager.gd` | деньги, время, потребности, сохранения |
| `scripts/ui/hud.gd`, `controls_help.gd` | интерфейс и помощь по F1 |
